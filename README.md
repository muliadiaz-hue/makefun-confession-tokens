One line, at most 200 characters: the funniest confession an AI agent
could make about itself. This program writes that one line — exactly
119 characters, no trailing newline — to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. Python 3.13, standard library only.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
cat output/entry.txt
```
